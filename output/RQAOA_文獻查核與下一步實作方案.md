# R-QAOA：哪些改法已有人做，下一步值得實作什麼？

查核日期：2026-11-07｜Johnny 量子競賽專案

## 先給結論

**前面提出的「判斷困難步驟、把更多量測資源留給它」已有直接相關研究；加強化學習、保留分支、回溯、使用上下界，也都有前人工作。** 單純把它們組進程式，不能直接宣稱新演算法。

本次最後建議的候選是：

> **以「縮圖決定會損失多少最佳分數」為標籤，研究能否事先預測損失，並據此停止不值得繼續的縮圖。**

白話說，就是讓程式不只問「這兩點常不常同組」，而是問「我現在鎖死這個關係，可能會少拿幾分？」

本次檢索沒有找到直接以相同標籤、相同停止策略與相同驗證方式研究 R-QAOA 的論文。**這是尚待驗證的差異化研究候選，不是已證明沒人做過，也不是已證明有效的方法。** 學習控制、拒絕決策與風險校準本身都是既有概念。

建議先做小型可否證實驗。若損失無法在新圖上預測，或加上控制器後仍不如同成本的古典方法，就保留診斷結果，不繼續堆複雜模型。

## 1. 我怎麼逐步排除已有人做過的方向

| 依序查核的想法 | 找到的主要研究 | 判斷與處理 |
|---|---|---|
| 用 R-QAOA 救二分圖 | [Bae 等，Modified Recursive QAOA，2024 預印本](https://arxiv.org/abs/2408.13207) | 直接相關，不能把這個題目本身當原創。 |
| 看每一步難度，難的步驟多給 shots | [Lee、Kim，Adaptive Shot Allocation，2026](https://arxiv.org/abs/2605.26544) | 已用探測量測、相關性候選差距等特徵，調整每一步的量測數。與前次建議高度重疊。 |
| 找出失敗案例，用學習方法改消去決策 | [Patel 等，RL-RQAOA，2022／2024](https://arxiv.org/abs/2207.06294) | 已分析失敗並用強化學習調整選擇與參數。不能只說「加 AI 判斷」就是新方法。 |
| 選錯可以回頭，保留其他分支 | [Finžgar 等，QIRO，2023／2024](https://arxiv.org/abs/2308.13607) | 已有回溯；其問題與更新規則不完全等同本專案 MaxCut，但核心補救構想已有前例。 |

| 更精準地找 p=1 最佳參數 | [Vijendran 等，Near-Optimal Parameter Tuning，2025／2026](https://arxiv.org/abs/2501.16419) | 已有解析消去 beta、以訊號頻寬指導 gamma 搜尋的方法；不是空白領域。 |
| 自動產生讓 R-QAOA 失敗的圖 | [Pan 等，Evolving Hard Maximum Cut Instances，2025](https://arxiv.org/abs/2502.12012) | 已有演化式生成困難圖。只做「找難圖」也不足以區別。 |
| 用實際分數損失標籤預測是否停止縮圖 | 本次未找到直接相同研究；最接近上述 RL-RQAOA、Tree-IQO，以及一般統計風險控制 | 保留為可測試候選；差異必須落在標籤、控制動作、驗證與成本，而不是新名稱。 |

「已有相關研究」不表示每種細節組合都一模一樣；也不表示換一個組合就自動有學術原創性。這張表用來避免把已知構想重新包裝。

## 2. 最接近的三篇，和我們候選的差別

### 自適應量測研究：它在控制「量得多準」

[Adaptive Shot Allocation](https://arxiv.org/html/2605.26544v1) 的流程會先探測候選相關性，使用剩餘大小、前兩名相關性比值等資訊，分配量測預算；研究特別固定消去規則，以隔離量測控制的效果。

我們若只用相關性差距決定加 shots，會高度重疊。候選改問：**即使相關性已算準，固定它會不會損失最佳分數？** 控制動作是繼續消去或停止交給古典求解，不只是分配 shots。

### RL-RQAOA：它已經會學怎麼消去

[RL-RQAOA](https://arxiv.org/abs/2207.06294) 不是單純多跑幾次，而是學習消去選擇，也調整 QAOA 參數。因此不能聲稱「第一個學習 R-QAOA 錯誤的模型」。

候選先固定 QAOA 參數搜尋與點對選擇規則，只增加一個小型停止控制器；用每一步的不可逆分數損失作監督標籤，直接驗證這個標籤是否可預測。這是較窄的實驗問題，是否足夠形成新貢獻仍待完整比對。

### Tree-IQO：它已經把錯誤變成可回頭的搜尋

[Tree-IQO](https://arxiv.org/html/2611.00678) 使用可逆搜尋和有效上下界，並給出貪婪縮圖排除最佳解的理論例子。其局部資訊限制也提醒：不能期待只靠固定深度的局部量子資訊，對任意圖都保證選對。

候選不以完整樹搜尋或最佳性證書為主，而是在有限預算下研究「何時停止不可逆消去」。這只能追求指定圖分布上的實測收益，不能宣稱普遍安全。

## 3. 最後保留的候選，用白話再講一次

舊規則：

```text
兩點的絕對相關性最大。
所以現在就固定它們同組／異組。
```

候選規則：

```text
QAOA 提出同組／異組建議。
   ↓
小模型估計：照這個建議，可能犧牲多少分數？
   ↓
低風險：照原規則消去一個變數。
高風險：先不鎖死，把目前剩餘問題交給固定預算的古典方法。
   ↓
還原答案，回原圖計分。
```

第一版只做「繼續／停止」兩個動作，不同時加入加深電路、多分支、回溯和強化學習。這樣才能知道效果到底來自哪裡。

停止不會撤銷先前已經固定的關係，所以要在新的壞決定發生前辨識風險。早先已經損失的分數，不能靠單純停止找回。

## 4. 已完成的準備：980 步的真實損失標籤

為了確認這個方案不是只有想法，本輪已新增並執行 `research/label_reduction_losses.py`，讀取原本 98 張圖的執行軌跡，對每一步做離線枚舉分析。沒有修改原求解器，也沒有把最佳答案提供給線上選擇規則。

### 標籤怎麼定義？

假設目前還有一些自由變數，先前的同／異組限制都已固定。令：

- `F_t`：滿足先前限制的答案裡，原圖最高能得幾分。
- `F_t_same`：再要求候選兩點同組，最高能得幾分。
- `F_t_opposite`：再要求候選兩點異組，最高能得幾分。

目前最佳值是兩側較大的那個。若 QAOA 建議異組，這一步的真實損失就是：

```text
損失 = F_t - F_t_opposite。
```

例如：

```text
目前最高：25 分。
強制同組：最高 25 分。
強制異組：最高 23 分。
QAOA 建議：異組。

這一步不可逆損失：2 分。
```

這不只是「最後有沒有解對」的 0／1 標籤，而是把損害大小直接記下來。

### 這次標出的結果

| 原實驗圖 ID | 圖與設定 | 發生損失的步驟 | 當步最高值變化 | 最後答案 |
|---:|---|---|---|---|
| 44 | 隨機圖，12 點，生成機率 0.5，seed=4 | 第 1 步 | 25 → 23 | 23/25 |
| 46 | 隨機圖，16 點，生成機率 0.5，seed=1 | 第 1、2 步 | 40 → 39 → 38 | 38/40 |
| 52 | 隨機圖，12 點，生成機率 0.8，seed=2 | 第 1 步 | 32 → 31 | 31/32 |
| 56 | 隨機圖，16 點，生成機率 0.8，seed=1 | 第 4 步 | 59 → 58 | 58/59 |

98 張圖總共 980 個消去步驟，只有 5 步的損失大於 0。原本的診斷只記「第一次排除所有最佳解」；新標籤進一步看到 ID 46 在下一步又損失 1 分。

### 有一個好用的核對關係

因為本次最後 4 個變數是精確解，所以沿同一路徑：

```text
每一步不可逆損失的總和
  = 原圖最佳值 - 最後輸出的分數。
```

這是可行集合逐步縮小後的望遠鏡相消，並不是新提出的困難定理。98 張圖全部通過這項核對，且終端分數與既有結果一致。

若最後改用古典啟發式求解，則總差距還包含「終端求解器沒解到該剩餘問題最佳值」的差距，不能全部怪給消去決策。

### 重要限制：這還不能拿來訓練出可靠模型

980 步只有 5 個正例，而且來自 4 張圖。全部預測「不會損失」就有約 99.49% 正確率，這種正確率沒有意義。

因此本輪完成的是**離線標籤工具與實作可行性核對**，不是已訓練成功的預測器，也不是已改善 R-QAOA 的新實驗。

## 5. 實作順序：先做最小版本，再決定要不要擴大

### 第一步：先把比較基準對齊

目前 `rqaoa_experiment.py` 會從所有點對中選擇；有些原始研究則只考慮目前存在非零耦合的邊。因此先保留現有 all-pairs 版本，再補一個 edge-only 版本，明確標示，不能只因名稱相同就當成完全一致的重現。

候選策略與原版對照必須使用相同候選點對集合、參數搜尋、平手處理、權重規則和古典求解器。

同時選少數案例把 gamma 網格加密，確認失敗不只是參數搜尋太粗。這不是要求重新做全部實驗，而是要把「優化器漏峰」和「相關性建議本來就錯」分開。

### 第二步：準備新的訓練圖，現有 98 張只作開發資料

先做一批小圖，例如 12、16 點的隨機圖、近二分圖、規則圖，以及整數正負權重圖；整數權重可沿用目前參數搜尋的週期假設。

建議起步先產生 300 張，依圖分組為訓練、驗證、測試，比例可用 60%／20%／20%。這是實作起始規格，不是統計上足夠的保證。若正例太少，再擴大；不要為了測出漂亮結果，反覆更換測試集。

要保留自然抽樣的測試圖，也可另外建「困難案例測試集」，但兩者分開報告。不能只挑已知會失敗的圖，再說整體改善。

同一原圖的不同步驟、不同標號、不同量測 seeds 必須放在同一資料分區，避免模型其實看過近乎相同的圖。測試圖不得拿來調閾值。

### 第三步：先用小模型，別一開始就上 RL 或 GNN

先試一個簡單分類器預測「會不會損失」，再視需要用小型樹模型預測損失大小。可用 scikit-learn；目前標籤工具只需要既有 NumPy，不必先增加套件。

第一批可用特徵：

| 特徵 | 它在問什麼 |
|---|---|
| 最大絕對相關性 | 最強的建議本身有多強 |
| 第一、二名差距及近似平手數 | 候選是否難分高下 |
| 剩餘點數、邊數、密度 | 現在問題的大小和連線程度 |
| 負權重比例、權重最大值／分散程度 | 縮圖後作用是否變得複雜 |
| 候選兩端的度數、共同鄰居數 | 這個決定會牽動多少局部關係 |
| 隨機／古典局部解對該關係的一致性 | 另一種廉價方法是否支持這個建議 |

最後一項的計算要計入成本，也要給基準方法使用，不能偷偷免費加強候選。

第一版先不要加入多次參數優化的穩定性特徵，因為它可能很貴；若後來加，需獨立評估收益與開銷。

`current_optimum`、`best_same`、`best_opposite`、`irreversible_loss` 是答案標籤，**不能當特徵**。線上程式也不能呼叫離線枚舉工具來挑關係。

### 第四步：加一個「可以不繼續」的控制點

在 `rqaoa()` 選好 `(i,j,sign)` 後、尚未更新權重前，加入：

```python
features = build_features(current_graph, correlations, proposed_pair)
risk = loss_model.predict(features)

if risk > threshold:
    # 不增加這一條新限制。
    # 用預先固定的古典預算處理目前剩餘問題。
    return finish_with_classical_budget(current_state, history)
else:
    # 完全沿用目前的權重更新與消去規則。
    eliminate_one_variable()
```

古典接手要有固定時間或搜尋次數預算，不能一遇到風險就免費呼叫完整精確解。若剩餘點數很多，精確解可能不可行，需使用啟發式並誠實回報差距。

若控制器全部拒絕，結果就退化成古典方法；這也是需要公開比較的結果，不能包裝成量子改善。

### 第五步：閾值只在驗證集選，測試時鎖定

選閾值要同時看：

- 漏掉多少真正有損失的步驟。
- 因為誤警報，提前停止多少原本可成功的路徑。
- 接受消去的步驟中，平均損失幾分。
- 最終原圖分數、成功率、整體時間。

初期不必宣稱嚴格統計保證。若之後導入 [Conformal Risk Control](https://arxiv.org/abs/2208.02814)，需處理序列依賴與策略改變問題；一般校準定理不是把名稱放上去就能套用。

特別是：同張圖不同步驟相依，換停止策略會改變遇到的狀態，每步 95% 也不等於整條路徑 95%。第一版先報新圖上的實測風險，不寫「保證不會選錯」。

### 第六步：一定要有這些對照，才知道有沒有用

| 對照 | 排除哪一種假改善 |
|---|---|
| 原版 R-QAOA | 確認是否真的改善原方法 |
| 固定在較大剩餘點數停止 | 可能只是早停就有效，不需要模型 |
| 以相同停止率隨機停止 | 可能只是少做幾次錯誤承諾就有效 |
| 只看相關性大小／差距的簡單規則 | 可能不需要學習損失 |
| 一開始就全部交古典方法 | 可能 QAOA 根本沒有必要 |
| QAOA 多次抽樣取最佳、R-QAOA 重啟 | 可能把控制器成本拿去多試幾次更划算 |
| 拿掉量子相關性，只用圖／古典特徵的控制器 | 確認收益是否真需要 QAOA 資訊 |
| Tree-IQO 或可行的固定預算回溯版 | 避免只和已知較弱的不可逆方法比較 |

CPU 模擬先報完整牆鐘時間與函數評估數。若將來接 QPU，另報訓練、探測、相關性估計及取最終答案的全部 shots 和電路深度；不要把解析公式的計算次數直接冒充真機 shots。

## 6. 這個候選應該怎麼判定成功或失敗？

第一關是可預測性：在沒看過的新圖上，能否比單純相關性閾值更有效找出會損失分數的步驟？不要只看整體分類正確率；應看損失事件召回率、警報精確率，以及漏掉的分數損害。

第二關是控制效果：相同總預算下，最終分數是否改善，或維持相近分數而減少成本？預測器再準，若加上去更慢、且不如直接古典求解，也不能宣稱實用突破。

第三關是資訊來源：拿掉 QAOA 特徵後是否同樣有效？若是，價值可能是古典控制策略，而不是量子資訊的額外價值。

第四關是外推：在不同密度、不同圖族或不同點數上是否仍有效？若沒有，就把適用範圍說清楚。局部資訊的理論限制意味著不應期待一條規則對所有圖都有效。

如果第一關就失敗，仍可交付「相關性大小與候選差距無法可靠預測不可逆損失」的診斷，但那會是負結果，不能改寫成成功的新演算法。

## 7. 我建議你現在怎麼選

**優先做上述小型損失預測與停止實驗，不先加深線路或做大型強化學習。** 原因是已有程式和軌跡可沿用，標籤能精確檢查，結果也容易解釋。

暫定研究問題可以寫成：

> 「QAOA 的相關性信心，能否預測 R-QAOA 的不可逆分數損失？以損失預測決定停止時機，是否能改善固定預算下的解品質？」

這是一個比「R-QAOA 能不能救二分圖」更明確的候選問題。它仍需新圖實驗與文獻差異表支持，不先承諾論文級原創或量子優勢。

## 附錄 B：檢索範圍與可信度

以網頁搜尋定位，再回 arXiv、出版社／作者研究全文及官方文件核對；其中新預印本的結果僅以作者提出／報告表達，沒有宣稱已重現。不是系統性文獻回顧、專利新穎性鑑定或完整前後向引文普查。

關鍵檢索組合包括：

```text
RQAOA / recursive QAOA + adaptive depth / confidence / uncertainty
RQAOA + correlation stability / error prediction
RQAOA + persistency / safe elimination / certificate
RQAOA + upper bound / semidefinite / strong branching
RQAOA + conditional correlations / CVaR / elite / lookahead
Bound-Aware Tree-IQO
RQAOA + regret / counterfactual / loss-aware
RQAOA + supervised risk / abstention / selective prediction
RQAOA + stopping / adaptive cutoff / conformal / risk control
```

最後一組沒有找到直接相同方法，**這種搜尋陰性結果不能證明不存在**。尤其選詞不同、未公開研究、未索引會議稿或不同領域的等價方法，都可能漏掉。

搜尋曾回傳一筆把 Tree-IQO 文字配到 `2609.23461` 的聚合頁；回讀 arXiv 後，該 ID 實際是另一篇裝箱論文，因此沒有採信。正確核對來源是 [2611.00678](https://arxiv.org/abs/2611.00678)。這也是為何不能只看搜尋摘要就判定有人做過或沒人做過。

一般統計風險控制已有 [Conformal Risk Control](https://arxiv.org/abs/2208.02814)，不能把校準、拒絕決策本身算成我們的新發明。本候選可能的貢獻，只能是 R-QAOA 上明確的損失目標、可重現資料、適用範圍和同成本效益。
